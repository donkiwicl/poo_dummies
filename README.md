# POO para Dummies, interactivo — DSY1102

Curso interactivo basado en el manual «Java, JavaFX y Persistencia para Dummies» de DSY1102 (Duoc UC).

- 14 estaciones: Java (1.1–1.6), JavaFX (2.1–2.4), Persistencia (3.1–3.3) y «Doctor de errores».
- Cada lección: idea simple (verde), chequeo rápido, código (amarillo), desafío y nivel jefe opcional (azul).
- Pensado para mantener la atención: pasos cortos, retroalimentación inmediata, sin puntaje en contra.
- Ajustes: tamaño de texto, lectura cómoda, modo foco, sin animaciones, lectura en voz alta y pausas.
- El avance se guarda solo en el navegador de cada estudiante (localStorage).

Código de ejemplo en JDK 21 y JavaFX 21.0.6.

## Publicación

Sitio estático de un solo archivo (`index.html`) servido con GitHub Pages desde la rama `main`, carpeta raíz.
